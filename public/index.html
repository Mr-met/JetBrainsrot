📋 Hướng Dẫn Phím Điều Khiển & Combo

                
              

              

                

                  
                  

                    
🔤 Kiểu Phím Chữ (WASD)

                    
W / S / A / D: Lên / Cúi / Trái / Phải

                    
J: Đánh thường / Chọn Menu

                    
K: Nhảy / Quay lại

                    
L: Tốc biến / Lướt nhanh

                    
U: Kỹ năng xa (Chưởng)

                    
I: Tuyệt kỹ (Tất sát / Ulti)

                    
O: Gọi Trợ thủ

                  

                  
                  

                    
🔢 Kiểu Phím Số (Mũi tên)

                    
↑ / ↓ / ← / →: Lên / Cúi / Trái / Phải

                    
1 (hoặc Num 1): Đánh thường / Chọn

                    
2 (hoặc Num 2): Nhảy

                    
3 (hoặc Num 3): Tốc biến / Lướt nhanh

                    
4 (hoặc Num 4): Kỹ năng xa (Chưởng)

                    
5 (hoặc Num 5): Tuyệt kỹ (Tất sát / Ulti)

                    
6 (hoặc Num 6): Gọi Trợ thủ

                  

                

                

                  🔥 Combo Tuyệt Kỹ:

                  • Xuống + Đánh (S+J hoặc ↓+1) | Lên + Đánh (W+J hoặc ↑+1)

                  • Xuống + Chưởng (S+U hoặc ↓+4) | Lên + Chưởng (W+U hoặc ↑+4)

                  • Siêu Tuyệt Kỹ: Xuống + Ulti (S+I hoặc ↓+5) hoặc Lên + Ulti (W+I hoặc ↑+5)

                  • Tích Năng Lượng: Nhấn giữ cùng lúc S+J (hoặc ↓+1)
